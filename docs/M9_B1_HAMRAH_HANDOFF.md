simplified to:

- portrait;
- public name and professional title;
- one main approved professional biography/resume narrative;
- one coherent `حوزه‌های کاری` presentation;
- related services;
- optionally restrained relevant articles;
- `درخواست ارزیابی` entry;

Do not create separate `روش کار` or `سابقه و آموزش` sections. Owner-approved education or
background belongs naturally inside the main biography. Never invent qualifications.

  `اگر دوست دارید، کمی بیشتر برایمان بنویسید` as friendly guidance/labeling; do not hide the

- Child age is a whole-year triage value with the wide sanity bound `0..120`. It is not an

  coordinate the next step. It must not imply booking or promise a response time.
